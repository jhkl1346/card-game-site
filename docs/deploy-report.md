# 무료 배포 서비스 조사 보고서 (2026-11-13)

`PROMPT.md`의 "무료 배포 구성"에 따라, 기억이 아니라 **오늘 각 서비스의 공식 문서를 직접 읽고** 정리했습니다.
문서에 적혀 있지 않은 것은 "문서에 없음"으로 표시했습니다. 확인을 받은 뒤 배포 구성을 확정합니다.

## 1. 추천 구성

| 역할 | 서비스 | 요금제 |
|---|---|---|
| 서버 + 화면 (한 곳에서 제공) | **Render** Free web service | 무료, 결제 수단 등록 안 함 |
| DB (PostgreSQL) | **Neon** Free | 무료, 카드 불필요 |
| CI·배포 실행 | GitHub Actions | 공개 저장소라 기본 러너 무료 |

- 주소: `https://<서비스이름>.onrender.com` 하나 (무료 서브도메인, 도메인 구입 없음)
- 서버가 빌드된 화면 파일도 함께 제공 → 로그인 쿠키가 같은 사이트라 `SameSite=Lax` 그대로, CORS 설정 불필요 (ARCHITECTURE.md 3장의 1순위 구성)

## 2. 서비스별 확인 결과

### Render (서버)
출처: render.com/docs/free, /docs/websocket, /docs/compute-plans, /docs/faq

| 항목 | 공식 문서 내용 | 이 게임에 미치는 영향 |
|---|---|---|
| 카드 등록 | 무료 서비스에 필요하다는 내용 없음. "결제 수단이 없으면 한도 초과 시 무료 서비스를 그달 동안 **정지**" | 카드를 등록하지 않으면 **과금되지 않고 정지만 됨** |
| 잠듦 | 15분 동안 들어오는 요청이 없으면 잠듦. **WebSocket 메시지도 활동으로 침** | 게임 중에는 안 잠듦. 아무도 없으면 잠듦 |
| 깨어나는 시간 | 약 1분 | 이미 만든 "서버를 깨우는 중입니다" 화면이 뜸 |
| 월 사용량 | 워크스페이스당 750시간 (잠든 시간은 안 셈), 넘으면 다음 달까지 정지 | 서비스 1개면 한 달 내내 켜 있어도 744시간 이내 |
| 사양 | 0.1 CPU, 512MB 메모리 | 방 수 상한(`ServerLimits.maxRooms`)을 낮게 잡을 예정 |
| WebSocket | 지원, 최대 연결 시간 제한 없음. 배포·재시작 때 끊김 | 재접속 처리 이미 있음 |
| 재시작 | "무료 서비스는 언제든 재시작될 수 있음" | 진행 중이던 판은 무효, 칩 환불 (이미 구현) |
| 디스크 | 임시 디스크 (재시작·잠듦마다 지워짐) | DB를 외부(Neon)에 두므로 문제없음 |
| Render 무료 Postgres | **생성 30일 후 만료, 14일 뒤 데이터 삭제**, 1GB | 칩·전적이 사라지므로 **사용 안 함** |
| 잠 안 들게 계속 호출하기 | 허용·금지 둘 다 문서에 없음. "비정상적으로 많은 트래픽"은 정지될 수 있다고 함 | `PROMPT.md` 원칙대로 **하지 않음** |
| 화면 + API 한 서비스 | FAQ: "가능할 수도 있지만 권장하지 않음" (정적 사이트를 따로 두라는 뜻) | 아래 4번 참고 |

### Neon (DB)
출처: neon.com/pricing (2026-11-04 갱신), /docs/introduction/plans (2026-11-12 갱신), /docs/introduction/regions

| 항목 | 공식 문서 내용 | 영향 |
|---|---|---|
| 카드 | "영구 무료, 카드 불필요" | |
| 저장 용량 | 프로젝트당 1GB | 판별 기록 90일 보관·정리 중이라 충분 |
| 계산 시간 | 프로젝트당 월 100 CU-시간 (0.25 CU면 400시간) | 5분 쉬면 멈추므로 실사용 시간만 셈 |
| 잠듦 | 5분 동안 쿼리 없으면 멈춤, 다음 쿼리에 수백 ms 안에 재시작 | 첫 쿼리만 살짝 느림 |
| 한도 초과 | 과금 없음. 계산 정지 또는 쓰기 차단, **데이터는 삭제 안 함** | |
| 오래 안 쓰면 | AWS 지역은 정지·삭제 안 함 (90일 삭제 규정은 폐지된 Azure 지역만) | |
| 지역 | AWS 싱가포르(ap-southeast-1) 등 8곳 | 한국과 가까운 싱가포르 선택 예정 |

### GitHub Actions
출처: docs.github.com/en/billing/concepts/product-billing/github-actions
- 이 저장소는 **공개(public)** 라서 GitHub 기본 러너 사용이 무료입니다("공개 저장소에서는 무료").
- 다시 비공개로 바꾸면: 무료 계정에 매달 $12어치(Linux 2코어 기준 약 2,000분) 포함, **결제 수단이 없으면 다 쓴 뒤 막힐 뿐 과금되지 않음**. CI 한 번은 약 2~3분입니다.

## 3. 제외한 후보와 이유

| 후보 | 이유 |
|---|---|
| Koyeb | 무료 인스턴스 1개(512MB), 지역이 프랑크푸르트·워싱턴뿐(한국에서 멂). 잠든 서비스를 WebSocket으로 깨우면 "몇 분만 유지"된다고 문서에 있음. 카드 등록 필요 여부가 문서로 확인되지 않음. 무료 Postgres는 월 5시간 |
| Fly.io | 새 계정은 무료 요금제 없음(7일 $1 체험), 이후 카드 필수·사용량 과금 |
| Oracle Cloud Always Free | 공식 FAQ 페이지가 자동 조회를 거부(403)해서 **확인하지 못함**. 기억에 의존하지 않는다는 원칙에 따라 제외 |
| Supabase (DB) | 무료 500MB, **1주일 안 쓰면 일시 정지**, 직접 연결은 IPv6만(Render에서 쓰려면 풀러 경유). 친구끼리 가끔 쓰는 용도엔 Neon이 더 맞음 |
| Vercel·Netlify·Cloudflare Pages (화면만 따로) | 화면과 서버 도메인이 갈리면 로그인 쿠키가 제3자 쿠키가 되어 사파리 등에서 막힐 수 있음 |

## 4. 남은 위험과 대응

1. **Render가 "화면+API 한 서비스"를 권장하지 않음**: 금지는 아니고, Node 서버가 정적 파일을 함께 주는 건 흔한 방식입니다. 쿠키 문제를 피하는 이점이 더 커서 이 구성을 추천합니다. 문제가 생기면 Render 무료 정적 사이트를 따로 두고 쿠키를 `SameSite=None`으로, CORS를 허용 출처 고정으로 바꿔 옮길 수 있습니다(화면 쪽 서버 주소 설정 `VITE_SERVER_URL`은 이미 있음).
2. **잠듦**: 15분간 아무도 없으면 잠들고, 첫 접속은 약 1분 걸립니다. 계속 호출해서 깨워 두는 방법은 쓰지 않습니다.
3. **메모리 512MB**: 동시 방 수 상한을 50 → 10개 정도로 낮출 예정입니다(`ServerLimits`, 배포 환경변수로 조정 가능).
4. **언제든 재시작**: 진행 중이던 판은 무효가 되고 판 시작 전 칩으로 환불됩니다(6단계에서 구현).
5. **조건 변경**: 무료 조건은 바뀔 수 있어 README에 확인 날짜와 링크를 적어 둡니다.

## 5. 승인해 주시면 진행할 일

- 제가 할 일: 서버가 화면 파일을 함께 제공하도록 수정, `render.yaml`(배포 설정), 배포 가이드(환경변수), 수동 실행 배포 워크플로(`workflow_dispatch`), README 갱신
- **직접 해 주셔야 할 일** (외부 서비스 가입은 제가 대신하지 않습니다):
  1. Neon 가입 → 프로젝트 생성(싱가포르) → 접속 문자열을 Render 환경변수에 직접 입력
  2. Render 가입 → GitHub 저장소 연결 → 결제 수단은 **등록하지 않기**
  3. 비밀 값(DB 접속 문자열)은 채팅에 붙여 넣지 말고 Render 화면에 직접 넣어 주세요
