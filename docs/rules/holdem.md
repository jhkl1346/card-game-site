# 텍사스 홀덤 규칙과 가정

PROMPT.md에 정해진 규칙은 그대로 따르고, 정해지지 않은 부분은 아래처럼 가정해 `HoldemRules` 설정으로 바꿀 수 있게 합니다.

## 1. PROMPT.md에서 정해진 규칙
- 인원 2~9명, 홀카드 2장씩, 보드 5장(플랍 3 → 턴 1 → 리버 1)
- 딜러 버튼, 스몰블라인드/빅블라인드 회전
- 액션: 폴드, 체크, 콜, 벳, 레이즈, 올인 (No-Limit)
- 올인과 사이드팟, 쇼다운 시 7장 중 최고 5장 판정, 동점 시 팟 분할 (족보 판정기는 7포커와 공유, 무늬는 우열에 영향 없음)
- 번 카드: 플랍 전(옵션, 기본 켜짐)·턴 전·리버 전에 덱 맨 위 1장을 버림
  - 서버의 `burnedCards`에만 저장, 클라이언트에는 **개수만** 전송, 판이 끝난 뒤에도 공개하지 않음
  - 최대 9인 기준 필요 카드 = 홀카드 18 + 번 3 + 보드 5 = 26장 < 52장 (시작할 때 검증)

## 2. 가정한 규칙

### 2.1 한 판(핸드) 단위
- 엔진은 **한 판**을 진행합니다. 다음 판의 딜러 버튼은 방(서버)이 `nextButtonIndex`로 정해 넘깁니다.
- 칩이 0인 사람은 그 판에 앉히지 않습니다(방에서 제외하거나 관전).

### 2.2 블라인드와 순서
- 3명 이상: 버튼 왼쪽이 스몰블라인드(SB), 그다음이 빅블라인드(BB).
- **2명(헤즈업)**: 버튼이 SB를 내고 프리플랍에 먼저, 플랍 이후에는 나중에 액션합니다. (표준 규칙)
- 블라인드를 낼 칩이 모자라면 가진 칩만 내고 올인합니다. 이때도 콜 금액은 원래 BB 금액입니다.
- 프리플랍은 BB 왼쪽부터, 플랍 이후는 버튼 왼쪽에서 가장 가까운 사람부터 시작합니다.
- 모두 콜만 했으면 BB에게 체크/레이즈할 기회(옵션)가 있습니다.
- 홀카드는 SB부터 시계 방향으로 한 장씩 두 바퀴 나눕니다.

### 2.3 No-Limit 베팅 금액
| 액션 | 조건 | 금액 |
|---|---|---|
| 벳 | 이번 라운드에 아무도 베팅하지 않았을 때 | 최소 BB, 최대 내 칩 전부 |
| 레이즈 | 앞사람이 베팅했을 때 | **최소: 현재 베팅 + 직전 베팅/레이즈 증가분**, 최대 내 칩 전부 |
| 올인 | 언제든 (레이즈 권리가 있을 때) | 남은 칩 전부 |

- 벳·레이즈 금액은 "이번 라운드에 내가 낸 총액(to)" 기준으로 받습니다. 예) BB 100에서 300으로 레이즈 → 다음 최소 레이즈는 500.
- **짧은 올인**: 최소 레이즈에 못 미치는 올인 레이즈는 이미 액션한 사람에게 레이즈 권리를 다시 주지 않습니다(콜·폴드만 가능). 아직 액션하지 않은 사람은 레이즈할 수 있습니다.
  - 짧은 올인 여러 개가 합쳐 최소 레이즈를 넘는 경우의 재개방 규칙은 단순화를 위해 적용하지 않습니다.
- 첫 베팅(벳)이 BB보다 작은 올인이어도 다음 최소 레이즈 증가분은 BB입니다.

### 2.4 승부와 팟 분할
- 한 명만 남으면 즉시 이기고 카드를 공개하지 않습니다.
- 더 베팅할 사람이 1명 이하면 남은 보드를 (번 카드 규칙 포함) 끝까지 펼친 뒤 쇼다운합니다.
- 쇼다운에서는 끝까지 남은 사람의 홀카드를 공개합니다. 번 카드는 공개하지 않습니다.
- 나누어떨어지지 않는 칩(홀수 칩)은 **버튼 왼쪽에서 가장 가까운 승자부터** 1개씩 줍니다. (`oddChipRule: 'leftOfButton'`)

### 2.5 그 밖의 처리
- 턴 시간이 지나면 체크할 수 있으면 체크, 아니면 폴드합니다.

## 3. HoldemRules 기본값
| 설정 | 기본값 |
|---|---|
| `burnBeforeFlop` | `true` |
| `burnBeforeTurn` | `true` |
| `burnBeforeRiver` | `true` |
| `oddChipRule` | `'leftOfButton'` |
