# 훌라(Hula) 규칙과 가정

훌라는 지역/하우스 룰 차이가 커서, PROMPT.md에 정해진 것 외의 모든 세부 규칙을 `HulaRules` 설정으로 분리합니다.
"확인 필요" 항목은 사용자 확인을 받아 확정합니다.

## 1. PROMPT.md에서 정해진 규칙
- 인원 2~4명, 52장 + 조커(옵션), 각자 7장
- 매 턴: ① 덱 또는 버린 더미에서 1장 가져오기 → ② (가능하면) 멜드 등록 → ③ 1장 버리기
- 멜드: 같은 숫자 3장 이상(세트), 같은 무늬 연속 숫자 3장 이상(런). 이미 등록된 멜드에 붙이기 가능
- 손패를 먼저 모두 털면 승리(훌라). 덱이 떨어지면 라운드 종료, 남은 카드 점수가 가장 낮은 사람이 승리
- "스톱" 옵션(손패 점수가 낮을 때 라운드 종료 선언)
- 카드 점수: A=1, 2~10=숫자, J/Q/K=10~13 중 설정, 조커=설정. 정산 규칙도 설정

## 2. 가정한 규칙

### 2.1 준비
- 딜러(방이 판마다 돌림) 다음 자리부터 시계 방향으로 7장씩 나누고, 덱 맨 위 1장을 펼쳐 버린 더미를 시작합니다.
- 첫 차례는 딜러 다음 자리입니다.
- 조커는 기본 **사용 안 함**(`jokers: 0`). 켜면 1~2장, 아무 카드나 대신할 수 있고(와일드), 손에 남으면 `jokerPoints`(기본 30점)입니다.

### 2.2 멜드
- 세트: 같은 숫자 3~4장(조커 포함 가능, 같은 무늬 중복 불가).
- 런: 같은 무늬 연속 3장 이상. **A는 A-2-3처럼 낮게도, Q-K-A처럼 높게도** 쓸 수 있지만 K-A-2처럼 넘어갈 수는 없습니다. (`aceHighInRun: true`)
- 붙여놓기: 테이블에 있는 **누구의 멜드에든** 붙일 수 있습니다. (`layOffToOthers: true`)
- 한 턴에 여러 멜드 등록과 붙여놓기를 할 수 있습니다.
- 등록한 멜드는 되돌릴 수 없습니다.

### 2.3 승리와 종료
- 버리기까지 마치고 손패가 0장이면 승리합니다. 멜드·붙여놓기만으로 손패가 0장이 되면 버리지 않고 바로 승리합니다.
- **훌라 보너스**: 그 판에 한 번도 등록하지 않다가 한 턴에 손패 전부를 털고 이기면 "훌라"로 정산 배수 ×2 (`hulaMultiplier: 2`).
- 가져올 차례에 덱이 비어 있으면 라운드가 끝나고, 남은 손패 점수가 가장 낮은 사람이 이깁니다. 같으면 딜러 다음 자리에서 가까운 사람이 이깁니다.

### 2.4 카드 점수 (기본값)
| 카드 | 점수 |
|---|---|
| A | 1 |
| 2~10 | 숫자 그대로 |
| J / Q / K | 각 10 (`faceCardPoints: 'ten'`, `'ranked'`로 바꾸면 11/12/13) |
| 조커 | 30 (`jokerPoints`) |

### 2.5 턴 시간 초과
- 가져오기 전이면 덱에서 가져오고, 등록 없이 **가장 점수가 높은 카드**를 자동으로 버립니다.
- 버린 더미에서 가져온 카드를 아직 쓰지 않았다면(3.1), 그 카드를 쓰는 첫 번째 등록·붙여놓기를 자동으로 한 뒤 위 방식대로 버립니다.

## 3. 사용자 확인으로 확정한 항목 (2026-11-12)

### 3.1 버린 더미에서 가져오기 (`discardPickup: 'mustUse'`)
- 버린 더미 맨 위 카드는 **그 턴에 바로 멜드 등록이나 붙여놓기에 쓸 수 있을 때만** 가져올 수 있습니다.
- 가져온 카드를 쓰기 전에는 버리기를 할 수 없고, 가져온 카드 자체를 버릴 수도 없습니다.
- `'free'`로 바꾸면 조건 없이 가져올 수 있습니다.

### 3.2 한국식 특수 규칙
- **7 단독 등록** (`sevenAlone: true`): 7은 한 장만으로도 멜드로 등록할 수 있습니다. 여기에 다른 7(세트)이나 같은 무늬의 6·8(런)을 붙일 수 있습니다.
- **땡큐**(차례가 아닐 때 버린 카드 가져가기)는 넣지 않습니다.
- **등록한 뒤에만 붙이기** (`layOffRequiresMeld: true`, 사용자 요청 2026-11-12): 자기 카드를 한 번이라도 등록해야 붙이기를 할 수 있습니다. 등록한 바로 그 턴부터 내 멜드와 남의 멜드 모두에 붙일 수 있습니다. 아직 등록하지 않았다면 버린 카드를 "붙이기용"으로 가져올 수도 없습니다.

### 3.3 스톱 (`stop`)
- 내 차례에 카드를 가져오기 **전**, 손패 점수가 `stopMaxPoints`(기본 **10점**) 이하일 때만 선언할 수 있습니다.
- 선언하면 라운드가 끝나고 모두의 손패 점수를 비교합니다.
  - 선언자 점수가 가장 낮으면(같은 점수 포함) 선언자가 이깁니다.
  - 아니면 실제 최저점자가 이기고, 선언자는 자기 점수의 **2배**(`stopFailMultiplier: 2`)를 냅니다.

### 3.4 칩 정산 (`settlement: 'points'`)
- 진 사람은 **자기 손에 남은 카드 점수 × 점당 칩**(`pointValue`, 방 설정)을 승자에게 냅니다.
- 훌라 보너스면 ×2, 스톱 실패한 선언자는 ×2를 적용합니다(둘이 겹치지는 않음).
- 테이블에 가진 칩보다 많이 낼 수는 없습니다.
- 정산은 판이 끝날 때 한 번만 계산하며, 칩 총량은 항상 보존됩니다.

## 4. HulaRules 기본값
| 설정 | 기본값 |
|---|---|
| `jokers` | `0` (1~2로 켤 수 있음) |
| `jokerPoints` | `30` |
| `faceCardPoints` | `'ten'` (J/Q/K 각 10점, `'ranked'`는 11/12/13) |
| `aceHighInRun` | `true` |
| `layOffToOthers` | `true` |
| `layOffRequiresMeld` | `true` |
| `sevenAlone` | `true` |
| `discardPickup` | `'mustUse'` |
| `stopEnabled` / `stopMaxPoints` / `stopFailMultiplier` | `true` / `10` / `2` |
| `hulaMultiplier` | `2` |
| `settlement` | `'points'` |
