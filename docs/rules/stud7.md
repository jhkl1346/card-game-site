# 7포커(Seven Card Stud) 규칙과 가정

PROMPT.md에 정해진 규칙은 그대로 따르고, 정해지지 않은 부분은 아래처럼 **가정**한 뒤 `Stud7Rules` 설정으로 바꿀 수 있게 합니다.
"확인 필요" 표시는 사용자 확인을 받아 확정할 항목입니다.

## 1. PROMPT.md에서 정해진 규칙
- 인원 2~5명
- 첫 3장: 비공개 2장 + 공개 1장. 이후 4·5·6번째는 공개, 7번째는 비공개로 1장씩 받아 총 7장
- 베팅 라운드 5번: 3·4·5·6·7장째를 받은 직후
- 액션: 삥, 체크, 콜, 따당, 쿼터, 하프, 풀, 다이
- 최종 7장 중 최고 5장 족보로 승부 (공통 족보 판정기), 한 명만 남으면 즉시 승리, 올인 시 사이드팟
- `Stud7Rules` 기본값
  - `firstRoundStarter: 'lowestOpenCard'` — 첫 라운드는 공개 카드가 가장 낮은 사람부터
  - `laterRoundStarter: 'highestOpenHand'` — 2라운드부터 공개 카드 패가 가장 높은 사람부터
  - `suitRank: 스페이드 > 다이아 > 하트 > 클로버` — 공개 카드 비교에서 숫자가 같을 때 순서
  - `tieBreakBySuit: false` — 최종 족보가 완전히 같으면 팟을 나눔

## 2. 가정한 규칙

### 2.1 판돈과 기본 단위
- **앤티(ante)**: 매 판 시작할 때 모든 참가자가 방 설정의 "판돈"만큼 냅니다. (`ante`)
- **기본 베팅 단위**: 앤티와 같은 금액. 삥 금액과 금액 반올림 단위로 씁니다. (`betUnit`, 기본값 = 앤티)

### 2.2 액션 정의
"콜 금액"은 내가 지금까지 이번 라운드에 낸 금액과 현재 최고 베팅의 차이입니다.
"판돈(팟)"은 앤티와 지금까지의 모든 베팅을 합친 금액입니다.

| 액션 | 언제 가능 | 내야 하는 금액 |
|---|---|---|
| 체크 | 이번 라운드에 아직 아무도 베팅하지 않았을 때 | 0 |
| 삥 | 이번 라운드에 아직 아무도 베팅하지 않았을 때 (첫 베팅) | 기본 단위 1개 |
| 콜 | 앞사람이 베팅했을 때 | 콜 금액 |
| 따당 | 앞사람이 베팅했을 때 | 콜 금액 + **직전 베팅(레이즈) 증가분만큼 더**. 예) 앞사람이 1,000 베팅 → 따당 2,000 / 이어서 2,000에 따당 → 3,000 |
| 쿼터 | 항상 (최대 베팅 제한 안에서) | 콜 금액 + (콜한 뒤의 판돈 × 1/4) |
| 하프 | 항상 | 콜 금액 + (콜한 뒤의 판돈 × 1/2) |
| 풀 | 항상 | 콜 금액 + (콜한 뒤의 판돈 × 1) |
| 다이 | 항상 (내 차례일 때) | 포기 |

- 쿼터·하프·풀 금액은 기본 단위로 **내림**합니다. (`potBetRounding: 'floor'`)
- 판돈 비율 계산은 "콜한 뒤의 판돈" 기준입니다. (`potBetBase: 'afterCall'`, 다른 값: `'beforeCall'`)
- 계산한 금액이 테이블에 남은 칩보다 많으면 남은 칩 전부를 냅니다(올인).

### 2.3 올인과 사이드팟
- 테이블에 가져온 칩까지만 걸 수 있습니다(테이블 스테이크). 모자라면 가진 만큼만 내고 올인이 됩니다.
- 올인한 사람은 자기가 낸 금액까지의 팟(메인팟/사이드팟)만 이길 수 있습니다. 사이드팟 계산은 홀덤과 공유합니다.
- 올인 금액이 모자라 정상적인 레이즈 크기에 못 미치면, 이미 액션한 사람에게 다시 레이즈할 권리를 주지 않습니다(콜·다이만 가능). — 홀덤 No-Limit 관례를 따름

### 2.4 베팅 라운드 진행
- 모든 남은 사람이 같은 금액을 냈거나 올인하면 라운드가 끝납니다.
- 시작하는 사람: 1라운드 `firstRoundStarter`, 2라운드부터 `laterRoundStarter` (공개 카드끼리 판정기로 비교, 같으면 `suitRank`로 가장 높은 카드의 무늬 비교)
- 한 명 빼고 모두 다이하면 그 사람이 즉시 팟을 가져가고, 카드를 공개하지 않습니다.
- 올인 등으로 더 베팅할 사람이 1명 이하면 남은 카드를 베팅 없이 끝까지 나눠 주고 쇼다운합니다.

### 2.5 승부와 팟 분할
- 최종 족보가 같으면 팟을 똑같이 나눕니다. 나누어떨어지지 않는 칩(홀수 칩)은 **이번 판 첫 라운드를 시작한 사람부터 순서대로** 1개씩 줍니다. (`oddChipRule: 'firstToActOrder'`)
- `tieBreakBySuit: true`이면 같은 족보끼리 최고 카드의 무늬(`suitRank`)로 승자를 가립니다.

## 3. 사용자 확인으로 확정한 항목 (2026-11-12)
| 설정 | 확정값 | 의미 |
|---|---|---|
| `maxRaisesPerRound` | `2` | 한 라운드에 한 사람이 레이즈(따당·쿼터·하프·풀)를 최대 2번. 삥은 레이즈로 세지 않음. `null`이면 제한 없음 |
| `maxBetAction` | `full` | 풀까지 허용. `half`로 바꾸면 풀 버튼이 사라짐 |
| `firstRoundActions` | 모든 액션 | 첫 라운드(3장째)도 다른 라운드와 같은 액션을 씀 |
| `chooseOpenCard` | `true` | 처음 3장을 모두 비공개로 받은 뒤, 각자 펼칠 카드 1장을 고름(액션 `open`, `cardIndex` 0~2). 고른 카드는 모두가 고를 때까지 숨겨 두었다가 한꺼번에 공개. 시간이 지나면 3번째 카드를 펼침. `false`면 3번째 카드가 바로 공개됨 |

## 4. 그 밖의 처리
- 턴 시간이 지나면 체크가 가능하면 체크, 아니면 다이로 자동 처리합니다. (공개 카드 고르기 단계에서는 3번째 카드를 펼침)
- 7번째 카드는 화면에서 뒷면으로 도착하고, 눌러야 내 화면에서 보입니다(화면 연출일 뿐 서버 데이터는 같음).
- 앤티를 낼 칩이 모자라면 가진 칩을 모두 내고 올인 상태로 시작합니다.
- 비공개 카드(상대의 1·2·7번째 카드)와 남은 덱은 `getState(playerId)`에 들어가지 않습니다. 남은 덱은 장수만 보냅니다. 쇼다운까지 간 사람의 카드만 판이 끝난 뒤 공개합니다.
